OmniRoute funmorawon ti wa ni itumọ ti ni ayika engine siwe. Ipo kan le ṣiṣẹ enjini kan taara (`caveman` tabi `rtk`) tabi opo gigun ti epo tolera ti o ṣiṣẹ awọn ẹrọ pupọ ni ibere.

## Awọn ọna

| Ipo          | Ọna ẹrọ                                                                                | Iṣawọle ti a pinnu                                           |
| ------------ | -------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `off`        | ko si                                                                                  | Itọju kiakia                                                 |
| `lite`       | Caveman Lite awọn oluranlọwọ                                                           | Ewu kekere nigbagbogbo-lori afọmọ                            |
| `standard`   | Caveman                                                                                | Idami-ara-ẹni kiakia                                         |
| `aggressive` | Caveman + history/tool summarizers                                                     | Awọn akoko iwiregbe gigun                                    |
| `ultra`      | Caveman + pruning awọn oluranlọwọ                                                      | Imularada aropin-ọrọ                                         |
| `rtk`        | RTK                                                                                    | Terminal, ikarahun, kọ, idanwo, ati iṣelọpọ git              |

### OmniGlyph funmorawon profaili

Ẹrọ `omniglyph` (package `omniglyph`, 1.4.0 +) gba profaili atunmọ ti a darukọ, ti a ṣeto ni agbaye nipasẹ `omniglyph.profile` ninu awọn eto funmorawon tabi fun igbesẹ nipasẹ atunto igbese opo gigun ti epo:

| Profaili      | Ààlà                                                                                                      |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| `aggressive`  | Aiyipada. Ilana ti awọn owo ti a tẹjade ṣe iwọn eto awọn aworan —, awọn iwe aṣẹ irinṣẹ ati itan-itan ipon |
| `balanced`    | Ṣe itọju ilu abinibi laaye, ṣe aabo awọn iyipada 8 ti o kẹhin, ṣubu itan-akọọlẹ pipade agbalagba          |
| `coding-safe` | Ṣetọju aṣẹ, awọn eto irinṣẹ ati iṣelọpọ irinṣẹ laaye, ṣe aabo awọn iyipada 12 to kẹhin                    |
| `passthrough` | Awọn ọna laisi iyipada; engine ti wa ni skipped                                                           |

Profaili jẹ a** aja, ko kan pakà** : `mergeCompressionProfileOptions` ninu package kọ lati jẹ ki olupe kan bori tun ọna ipadanu ti profaili naa ti wa ni pipade, nitorinaa `preserveSystemPrompt: false` -igbesẹ kan ko le tun mu funmorawon eto ṣiṣẹ labẹ `coding-safe`.

Ti wiwọn lori koodu koodu yii: `coding-safe` ati `balanced` gbe `minCompressChars` soke si iwọn rẹ ati tọju eto, awọn eto irinṣẹ ati awọn abajade ohun elo abinibi, nitorinaa igba ti ko ti ṣajọpọ itan sibẹsibẹ duro ni `below_min_chars` ati pe ẹrọ naa yipada ohunkohun. Ti o ni idi ti aiyipada jẹ `aggressive` kuku ju profaili to ni aabo julọ.

Package naa pinnu iwọn awoṣe tirẹ ati profaili lati iṣeto ni ayika rẹ. OmniRoute ko ṣe aṣoju ipinnu naa rara: ohun ti nmu badọgba naa pin ẹnu-ọna awoṣe si opin ihamọ julọ ti package, nitorinaa awọn eto agbegbe ti o gbalejo le dín atokọ laaye nikan, ma ṣe faagun rẹ kọja awọn owo idiyele OmniRoute.

## Iforukọsilẹ ẹrọ

Iforukọsilẹ n gbe ni `open-sse/services/compression/engines/registry.ts`. Awọn enjini ṣe afihan iwe adehun pinpin kan:

- `id`: id engine iduroṣinṣin gẹgẹbi `caveman` tabi `rtk`
- `apply(text, config)`: ipa-ọna ipaniyan ti a lo nipasẹ awọn paipu tolera
- `compress(input, config)`: ọna ipaniyan akọkọ ti n pada awọn iṣiro + ọrọ
- `getConfigSchema()`: pada apẹrẹ JSON-Schema ti atunto to wulo
- `validateConfig(config)`: pada `{ valid, errors[] }`

Iforukọsilẹ nlo `registerCompressionEngine(engine)` (tabi `registerEngine` fun awọn ọran ilọsiwaju), eyiti o pe `assertValidEngine()` ati `validateConfig(defaultConfig)` ṣaaju gbigba. Lo `unregisterCompressionEngine(id)` lati yọ ẹrọ kuro ni akoko asiko.

`strategySelector.ts` ṣe iforukọsilẹ awọn ẹrọ ti a ṣe sinu rẹ ṣaaju ṣiṣe funmorawon. Eyi jẹ ki awotẹlẹ, funmorawon akoko asiko, ipo tolera, awọn idanwo, ati awọn ẹrọ iwaju lo ọna ipaniyan kanna.

### funmorawon apejuwe MCP (jẹmọ)

Iforukọsilẹ ọtọtọ n ṣe akojọpọ awọn metadata apejuwe irinṣẹ MCP ni ipele iforukọsilẹ — wo `open-sse/mcp-server/descriptionCompressor.ts` ati [MCP-SERVER.md](../frameworks/MCP-SERVER.md). O tun lo awọn ofin Caveman ṣugbọn nṣiṣẹ lori metadata irinṣẹ, kii ṣe beere awọn ẹru isanwo.

### Afikun-itumọ ti enjini

Ni ikọja Caveman, RTK, ati LLMLingua-2, iforukọsilẹ n gbe ọpọlọpọ awọn ẹrọ isonu adanu/igbekalẹ amọja (ti a lo nipasẹ awọn opo gigun ti o tolera, papa isere, ati awọn idanwo):

| Enjini    | Id              | Ohun ti o ṣe                                                                                                                                                               |
| --------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CCR       | `ccr`           | Akoonu-Compress-Gbapada (H4): rọpo awọn bulọọki ọrọ ti o tobi pupọ pẹlu awọn itọkasi akoonu, nitorinaa awọn bulọọki repeated/large ni a firanṣẹ ni ẹẹkan ati tọka lẹhinna. |
| headroom  | `headroom`      | SmartCrusher (H3 + N5): ijuwe tabula ti ko ni ipadanu ti awọn ẹru isanwo-ọpọlọpọ JSON-array sinu fọọmu `[N rows]` columnar.                                                |
| ionizer   | `ionizer`       | Iṣapẹẹrẹ ila Head/middle/tail fun awọn bulọọki isokan ti o tobi pupọ, titoju aarin elided bi itọkasi akoonu- CCR.                                                          |
| igba-deup | `session-dedup` | Yiyọkuro iyipada-agbelebu ti a koju akoonu (TokenMizer-atilẹyin): npa ọrọ ti a ti rii tẹlẹ ni awọn iyipada iṣaaju ti igba kanna.                                           |

**CCR gbigba-ilana ilana (#8033):** ni igba akọkọ CCR rọpo ≥ 1 bulọọki ni ibeere kan, ẹrọ naa ṣe ipinnu ẹyọkan, idempotent `system` ifiranṣẹ (asiwaju pẹlu sentinel `[CCR protocol]` ) nkọ olupe naa ami ami → ọpa adehun: kini ami ami `[CCR retrieve hash=<24hex> chars=N]` tumọ si, pe hash gbọdọ jẹ dakọ verbatim (gbogbo awọn ohun kikọ hex 24 — mis-daakọ ti awọn hashes) ti o ṣeeṣe ki a daakọ ti awọn hashes “ `[dedup:ref sha=...]` asami tumo si "wo pada ninu itan", kii ṣe "ipe ọpa". Akọsilẹ ti wa ni itasi** nikan nigbati `tools[]` ti olupe ti kede pe o le de ọdọ `omniroute_ccr_retrieve` gangan** (`callerSupportsCcrRetrieve()` in `open-sse/services/compression/engines/ccr/protocolInstruction.ts`) — olupe ti o ni ibaramu ti OpenAI lai si ohun elo yẹn ko gba ilana kan lati pe nkan ti ko le de ọdọ. Idempotency ti wa ni imudara nipasẹ ṣiṣe ayẹwo itan-akọọlẹ ifiranṣẹ fun sentinel ṣaaju ki o to abẹrẹ, nitorinaa awọn ibeere titan-pupọ (eyiti o tun ṣe awọn ifiranṣẹ iṣaaju) ma ṣe akopọ akọsilẹ lẹẹkan ni titan.

## Caveman

Ipo Caveman dojukọ condensation atunmọ ti prose deede:

- ṣe itọju awọn bulọọki koodu, URLs, JSON, awọn ọna, ati data ti a ṣeto
- yọ awọn kikun, hedging, tun ọrọ, ati verbose asopo ọrọ
- ṣe atilẹyin awọn akopọ ofin faili ti o mọ ede ni `open-sse/services/compression/rules/`
- wa nipasẹ `standard` julọ, `aggressive`, ati awọn ipo `ultra`

Ilẹ dasibodu jẹ `Dashboard -> Context & Cache -> Caveman`.

Caveman upstream ṣe ijabọ `~75%` awọn ami itẹjade diẹ, awọn ifowopamọ apapọ `65%` ni awọn ami aṣepari pẹlu iwọn `22-87%` kan, ati ohun elo titẹ-funmorawon `~46%` kan. OmniRoute nlo nọmba igbewọle Caveman nigbati o ba n ṣe akosile awọn ifowopamọ prompt/context tolera; Ipo igbejade Caveman maa wa ẹya idahun-iwa ihuwasi lọtọ.

## RTK

Ipo RTK fojusi lori pipaṣẹ ati iṣelọpọ irinṣẹ:

- ṣe awari awọn kilasi iṣẹjade bii `git status`, `git branch`, `git diff`, Vitest/Jest/Pytest, awọn idanwo Cargo/Go, TypeScript/Vite/Webpack ṣe agbero, ESLint, npm audit/installs, awọn akọọlẹ Docker, ikarahun `find`/`grep`, awọn itọpa akopọ, ati awọn akọọlẹ jeneriki
- kan awọn asẹ JSON 49 lati `open-sse/services/compression/engines/rtk/filters/`
- ṣe atilẹyin opo gigun ti ọna asọye RTK: yiyọ ANSI, rọpo, ijade-kukuru kukuru, awọn laini strip/keep, gige-laini kọọkan, gige head/tail/max-line, ati ipadabọ on-ṣofo
- ṣe atilẹyin awọn asẹ iṣẹ akanṣe igbẹkẹle ni `.rtk/filters.json` ati awọn asẹ agbaye ni `DATA_DIR/rtk/filters.json`
- awọn ọna ila ANSI, ariwo ilọsiwaju, awọn ila ti a tun ṣe, ati awopọto ti ko ṣe iranlọwọ
- ṣe itọju awọn ikuna ṣiṣe, awọn ikilọ, awọn akopọ, awọn faili ti o yipada, ati ipo iru
- O le ṣe idaduro iṣẹjade aise aise ni yiyan fun recovery/debugging nipasẹ awọn ipa-ọna iṣakoso titọ

Ilẹ dasibodu jẹ `Dashboard -> Context & Cache -> RTK`.

Awọn alaye iṣẹ ṣiṣe fun awọn asẹ aṣa, igbẹkẹle, rii daju, ati imularada aise-jade ni ifiwe ni [`RTK_COMPRESSION.md`](./RTK_COMPRESSION.md).

RTK ṣe ijabọ awọn ifowopamọ `60-90%` fun titẹkuro aṣẹ-jade. Apeere README rẹ ṣe afihan igba koodu Claude iṣẹju 30 kan ti n lọ lati awọn ami `~118,000` si `~23,900`, tabi `79.7%` ti o fipamọ.

## LLMLingua-2 (Pruning Itumọ)

LLMLingua-2 mode ṣe** atunmọ tokini pruning** lori prose nipa lilo iyasọtọ ami ami ONNX kekere kan, ni ibamu pẹlu Caveman ti o da lori ofin ati awọn ẹrọ RTK :

- compresses prose ni ti kii-eto awọn ifiranṣẹ nikan; Awọn bulọọki koodu olodi ati awọn idabobo miiran ko yipada rara
- nṣiṣẹ backend `@atjsh/llmlingua-2` (ONNX nipasẹ `@huggingface/transformers`) ninu okun oṣiṣẹ, nitorinaa itọkasi awoṣe ko ṣe dina lupu iṣẹlẹ ibeere naa
- ni** stackable** (`stackPriority` 35): ninu opo gigun ti epo tolera o nṣiṣẹ lẹhin awọn ẹrọ igbekale (CCR, igba-dedup, headroom, Caveman) ṣugbọn ṣaaju `ultra`, niwọn igba ti pruning atunmọ jẹ imunadoko julọ lori ọrọ ti a fisinumọ tẹlẹ — fun apẹẹrẹ `rtk -> caveman -> llmlingua`
- **kuna-ṣi lori eyikeyi aṣiṣe** (ti o padanu iyan deps, spawn osise, fifuye awoṣe, itọkasi, tabi akoko ti pari) → ọrọ atilẹba ti jẹ dapada ko yipada, kii ṣe aṣiṣe rara

Ibi ẹrọ: `open-sse/services/compression/engines/llmlingua/`. Oju dasibodu jẹ `Dashboard -> Context & Cache -> LLMLingua`.

### Awọn awoṣe

Awoṣe aiyipada jẹ**TinyBERT** (`atjsh/llmlingua-2-js-tinybert-meetingbank`, ~ 57 MB, sare). A ti o ga-yiye** BERT-ipilẹ** awoṣe (`Arcoldd/llmlingua4j-bert-base-onnx`, ~ 710 MB) wa nipasẹ aaye `model` atunto engine. `@huggingface/transformers` ṣe igbasilẹ awoṣe ti o yan ni ọlẹ lati HuggingFace Hub sinu `${DATA_DIR}/models/llmlingua` lori ipe akọkọ (`modelStore.ts`); atunto `modelPath` kan bori awọn ojuami si ẹda agbegbe dipo (awọn fifi sori ẹrọ aisinipo / air-gapped).

### Awọn igbẹkẹle iyan & fi sori ẹrọ lori ibeere

Awọn prunable LLMLingua asiko isise akopọ ẹlẹgbẹ jẹ** iyan** . Awọn idii meji ni a kede bi `optionalDependencies` ni `package.json` ati tọju** ita** nipasẹ iṣelọpọ iṣelọpọ (`scripts/build/prepublish.ts` ko ṣe akopọ wọn):

| Package              | Ẹya (pin) | Awọn akọsilẹ                           |
| -------------------- | --------- | -------------------------------------- |
| `@atjsh/llmlingua-2` | `2.0.5`   | Apoti titẹsi; sọ awọn miiran bi ẹlẹgbẹ |
| `js-tiktoken`        | `^1.0.20` | Tokenizer                              |

`@huggingface/transformers` ti wa ni pinni ni `^4.2.0` (pín pẹlu awọn ọna ifibọ agbegbe ati ki o tun itopase sinu standalone lapapo); awọn ẹlẹgbẹ `@atjsh/llmlingua-2@2.0.5` lori rẹ pẹlu `"^3.5.2 || ^4.0.0"`, nitorinaa mejeeji Transformers.js v3 ati v4 ni atilẹyin. Lati 2.0.4, `@atjsh/llmlingua-2` ko nilo `@tensorflow/tfjs` mọ, eyiti o yọ oluranlọwọ ẹyọkan ti o tobi julọ (TensorFlow.js) kuro ninu akopọ SLM. Awọn idii meji ti o wa loke nikan ni awọn ẹlẹgbẹ SLM prunable. Didara `npm install` (dev) nfi akopọ iyan sori ẹrọ laifọwọyi ayafi ti awọn igbẹkẹle iyan ko ba kuro.

**Kini idi ti o beere:** apopọ ti npm ti a tẹjade, idii adaduro, ati ọkọ oju-omi aworan Docker** laisi** wọnyi deps lati duro tẹẹrẹ. Nigbati wọn ko ba si, ẹnu-ọna igbẹkẹle oṣiṣẹ (iwadii ipinnu `@atjsh/llmlingua-2` ni `worker.ts`) kuna ati ẹrọ** kuna-ṣi si ipalọlọ** — yiyan LLMLingua di no-op (ọrọ pada ko yipada, ko si aṣiṣe wọle). Lati muu ṣiṣẹ ni agbegbe gige kan, fi sori ẹrọ akopọ aṣayan:

```bash
# pin to the versions declared in package.json optionalDependencies
npm install @atjsh/llmlingua-2@2.0.5 js-tiktoken
```

Yiyọkuro `@tensorflow/tfjs` (2.0.4 +) yọkuro ~ 800 MB oluranlọwọ ti o jẹ gaba tẹlẹ — ifẹsẹtẹ to ku ni transformers.js + onnxruntime-node runtimes, pẹlu awoṣe TinyBERT (~ 57 MB) ti a ṣe igbasilẹ ni lilo akọkọ (kii ṣe nipasẹ npm).

Fun ayika:

- **Dev / `npm install`** — fi sori ẹrọ laifọwọyi ayafi ti o ba kọja `--omit=optional` (tabi `--no-optional`). Ko si igbese ti o nilo.
- **Npm agbaye (`npm i -g omniroute`) / adashe** — ṣiṣe aṣẹ fifi sori ẹrọ loke inu iwe ilana package ti a fi sii, tabi tun fi sii laisi yiyọ awọn deps yiyan.
- **Docker** — ṣafikun aṣẹ fifi sori ẹrọ ni ipele aworan ti ari; awọn ọkọ aworan ti a tẹjade tẹẹrẹ nipasẹ apẹrẹ.
- **VPS (PM2)** — fi sori ẹrọ sinu `node_modules` app naa, lẹhinna tun bẹrẹ ilana naa ki oṣiṣẹ naa tun ṣe iwadii ẹnu-bode naa.
- **Aise Next adaduro (`npm run build` → `.build/next/standalone/server.js`)** — awọn ọkọ oju omi itọpa ti o wa ni imurasilẹ NEITHER oṣiṣẹ tabi awọn deps iyan, nitorina ẹrọ naa dakẹ kuna-ṣii. `scripts/build/colocate-standalone.mjs` tun kan awọn mejeeji (Osise esbuild + iyan-dep pipade sinu igi adaduro); o nṣiṣẹ laifọwọyi nipasẹ kio `postbuild` npm lẹhin gbogbo kikọ. Idepotent, kuna-asọ nigbati awọn deps ko si.

**Jẹrisi pe o nṣiṣẹ:** pẹlu LLMLingua ti a ti yan, prose gidi n dinku (engine naa duro kuna-ṣisii), ati ibeere akọkọ nfa igbasilẹ awoṣe sinu `${DATA_DIR}/models/llmlingua`. Ẹnu naa mọọmọ ṣe iwadii `@atjsh/llmlingua-2` — nikan awọn ẹlẹgbẹ miiran jẹ ESM-nikan ati `require.resolve` ju wọn sori wọn paapaa nigba ti o wa ni bayi — nitorinaa oṣiṣẹ ṣi kuna-ṣii ti ẹlẹgbẹ eyikeyi ba padanu nitootọ ni akoko `import()`.

## Tolera Pipelines

Ipo tolera nṣiṣẹ awọn igbesẹ opo gigun ti epo ni ibere. Awọn aiyipada ni:

```txt
rtk -> caveman
```

Lo eyi fun awọn akoko ifaminsi-aṣoju nibiti itọka kan ṣajọpọ iṣẹjade aṣẹ pẹlu eniyan tabi oluranlọwọ prose. RTK dinku awọn igbasilẹ ohun elo alariwo ni akọkọ, lẹhinna Caveman rọpọ ede abinibi ti o ku.

Awọn igbesẹ paipu ti wa ni tunto pẹlu `stackedPipeline` ni awọn eto funmorawon tabi nipasẹ funmorawon combos.

Nigbati awọn ẹrọ mejeeji ba dinku fifuye isanwo ti o yẹ kanna, agbo ifowopamọ:

```txt
combined = 1 - (1 - RTK savings) * (1 - Caveman input savings)
average  = 1 - (1 - 0.80) * (1 - 0.46) = 89.2%
range    = 1 - (1 - 0.60..0.90) * (1 - 0.46) = 78.4-94.6%
```

## MCP Wiwọle Tree Filter

Àlẹmọ ọlọgbọn-igi iraye MCP jẹ Layer funmorawon lẹhin-ipaniyan ti o nṣiṣẹ lori MCP** irinṣẹ esi** , kii ṣe lori awọn ibere tabi ọrọ-ọrọ. O ṣe ifọkansi irayesi-igi ati awọn iwọn isanwo aworan aṣawakiri ti a pada nipasẹ awọn irinṣẹ bii Playwright, lilo kọnputa, ati aṣawakiri-automation MCP olupin.

### Ohun ti o ṣe

1. **Yiyọ ariwo** — yọkuro awọn titẹ sii generic/text ofo (`- generic:`, `- text: ""`)
2. **Arakunrin ibale** — nigbati ≥ `collapseThreshold` (aiyipada 30) awọn laini itẹlera jẹ awọn atunwi igbekale, o ṣubu wọn sinu `collapseKeepHead` akọkọ (aiyipada 10) awọn ila + a ka akopọ + awọn ila `collapseKeepTail` ti o kẹhin (aiyipada 5)
3. **Itoju Ref** awọn ìdákọró — `[ref=eXX]` ti a beere nipasẹ Playwright/computer-use ko ni fọwọkan rara
4. **Gidigidi truncation** — ti ọrọ ba tun kọja `maxTextChars` (aiyipada 50,000), awọn gedu pẹlu itọka lilọ kiri ki aṣoju le tẹsiwaju ṣiṣẹ

### Enjini ipo

```txt
open-sse/services/compression/engines/mcpAccessibility/
  index.ts            ← smartFilterText() entry point
  collapseRepeated.ts ← sibling-collapse algorithm
  constants.ts        ← DEFAULT_MCP_ACCESSIBILITY_CONFIG
```

### Iṣeto ni

Ṣakoso nipasẹ `compression.mcpAccessibility` ni awọn eto agbaye (iṣiwa 056). Eto aiyipada:

```json
{
  "enabled": true,
  "maxTextChars": 50000,
  "collapseThreshold": 30,
  "collapseKeepHead": 10,
  "collapseKeepTail": 5,
  "minLengthToProcess": 2000
}
```

Àlẹmọ naa jẹ lilo nikan si awọn ẹru isanwo abajade-irinṣẹ ti `type` jẹ `"text"` ati ẹniti ipari rẹ kọja `minLengthToProcess`. Ko kan funmorawon kiakia tabi beere awọn fifuye isanwo.

### Awọn ifowopamọ ti o ti ṣe yẹ

60–80% lori awọn abajade irinṣẹ fọto fọto aṣawakiri, da lori idiju oju-iwe. Algorithm iparun jẹ O(n) ni kika laini ati ṣafikun airi aifiyesi.

## Awọn ibeere pataki / itọsọna oniṣẹ (CCR & idinku igba)

CCR (`ccr`) ati `session-dedup` rọpo tabi gbe ọrọ kuro ki o fi a** asami** sile. Abala yii jẹ itọkasi onišẹ fun sisopọ alabara soke, kika awọn asami meji, ati gbigba pada tabi ṣe iwadii akoonu ti o parẹ. Mekaniki ti kọọkan engine ti wa ni bo loke; eyi ni "bawo ni MO ṣe nṣiṣẹ" Layer.

### Awọn gbigbe & awọn aaye ipari

Olupin MCP ti o ṣafihan awọn irinṣẹ CCR le de ọdọ awọn ọna mẹta. URL ipilẹ aiyipada jẹ `http://localhost:20128` (`OMNIROUTE_BASE_URL`):

| Gbigbe                            | URL / pipaṣẹ                            | Awọn akọsilẹ                                                                                                                         |
| --------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| HTTP ṣiṣanwọle (onibara, iṣeduro) | `http://localhost:20128/api/mcp/stream` | Awọn endpoint lọwọlọwọ MCP ibara sọrọ si.                                                                                            |
| Legacy SSE singleton              | `http://localhost:20128/api/mcp/sse`    | Agbalagba singleton irinna. O** tilekun** awọn akoko ṣiṣan; lo awọn onibara `streamable-http` lodi si `/api/mcp/stream`, kii ṣe eyi. |
| stdio                             | `omniroute --mcp`                       | Fun IDE MCP konfigi ti o spawn awọn ilana. Ko si asia `--dev` ; `omniroute --mcp` ni aaye titẹsi stdio.                              |

### Awọn ipele ibi ipamọ (kini o ye fun atunbẹrẹ)

CCR ni a** meji-ipele** itaja, kii ṣe ni-iranti-nikan:

- **Gbona ni-iranti ipele** — fun-block fila 2 MiB, fun-akọkọ 16 MiB, agbaye 64 MiB. Awọn titẹ sii aiyipada si 24 h TTL (o pọju awọn ọjọ 7). Imupadabọ MCP ni kikun lati iranti ni 256 KiB; ohunkohun ti o tobi tun le de ọdọ nipasẹ awọn ipo larin / grep.
- **Tier SQLite ti o tọ** (`ccr_blocks`, `COMPRESSION_CCR_DURABLE_STORE`, titan nipasẹ aiyipada) — ṣe atilẹyin ipele inu-iranti nitori idinamọ kan yege kuro LRU, tun bẹrẹ, tabi ibalẹ gba pada lori apẹẹrẹ miiran. Ilana naa tọju TTL bulọọki, nitorinaa bulọki ti o kọja TTL rẹ lọ kuro ni awọn ipele mejeeji.

Awọn oluso mẹta jẹ ki ipele ti o tọ ni opin — idina kan duro iranti-nikan nigbati:

1. Àkọsílẹ ti pari** 512 KB** (`MAX_DURABLE_BLOCK_BYTES`);
2. akoko asiko jẹ akoko asiko awọsanma (ko si disk agbegbe);
3. `COMPRESSION_CCR_DURABLE_STORE=false`.

Nitorinaa “bulọọki naa parẹ” kii ṣe itan atunbẹrẹ ibora: bulọọki sub-512 KB kan lori agbegbe kan, akoko asiko-awọsanma wa laaye lati tun bẹrẹ nipasẹ ipele ti o tọ titi ti TTL rẹ yoo fi pari. Wo [itọkasi Ayika](../reference/ENVIRONMENT.md) fun oniyipada.

Eyi jẹ ẹya** moomo wo-pada** , kii ṣe pipadanu tabi aṣiṣe. | Ṣe** kii ṣe** pe eyikeyi ọpa ati ki o ṣe** kii ṣe** gbiyanju lati "ṣe atunṣe" rẹ. ### Onibara prequisites

- **Bọtini (sitẹdio):** Olupe stdio ko ni idanimọ ibeere-kọọkan, nitorina o jẹri pẹlu `OMNIROUTE_API_KEY` (ti a ṣeto sinu `env` olupin MCP ). Laisi rẹ olupe naa jẹ ailorukọ ati awọn irinṣẹ ti o nilo olori ile-iwe le dinku.
- **`tools[]` jẹ ipo iṣaaju abẹrẹ.** Ilana imupadabọ CCR (#8033) jẹ itasi** nikan** nigbati `tools[]` ti o polowo ibeere naa fihan pe alabara le de ọdọ `omniroute_ccr_retrieve` nitootọ. Baramu jẹ ibaamu-itọpa ti o ni opin nipasẹ oluyapa (`__`, `.`, `/`, `:`) — rara — substring igboro nitorina orukọ ti o ni aaye gẹgẹbi `mcp__gateway__omniroute_ccr_retrieve` ṣi ka. Ti ko si tabi ti ko baamu `tools[]` tumọ si itọnisọna jẹ _not_ itasi, nipasẹ apẹrẹ.
- **`codemode:false` (awọn onibara OpenCode ).** OpenCode aiyipada si Ipo koodu, eyiti o ṣe ipolowo awọn irinṣẹ abinibi nikan si awoṣe ati** ko ṣe** fi awọn irinṣẹ MCP sori atokọ `tools[]` abinibi. Ṣeto `codemode: false` lori titẹsi olupin MCP ki awọn irinṣẹ `omniroute_ccr_*` ti wa ni ipolowo. Eyi jẹ a** onibara** eto, kii ṣe ọkan OmniRoute kan. Ko gba itọni CCR itasi sibẹ: OpenCode lorukọ ọpa `<server>_<tool>` kan, nitorinaa olupin ti a npè ni `omniroute` ṣiṣafihan `omniroute_omniroute_ccr_retrieve`, ati pe `_` kii ṣe ọkan ninu awọn iyapa ti o baamu.
- **Awọn olori ile-iwe.** Ibi ipamọ ati igbapada wa ni iyasọtọ fun ipilẹṣẹ ti o jẹri (fun bọtini API ). Bọtini kan rii awọn bulọọki tirẹ nikan.

### Awọn ifilelẹ igbapada & pagination

Awọn abajade ọrọ irinṣẹ MCP jẹ gige ni ayika `mcpAccessibility.maxTextChars` (aiyipada `50000`). Imupadabọ `full` ti bulọọki kan ni 256 KiB —** ko si unbounded ni kikun gba** . Nigbati `chars=N` bulọọki kan ba tobi, ṣe oju-iwe rẹ dipo fifa gbogbo nkan naa:

- Ofin ti atanpako:**`chars > 40000` → lo kan `mode`** , kò a igboro ni kikun.
- `mode:"grep"` — regex `pattern` ti o baamu laini nipasẹ laini, to awọn laini ibaamu 1,000 (`unique: true` drops tuns), o kere julọ fun “wa laini kan ti Mo nilo.”
- `mode:"lines"` — ila ila 1-itọka; nilo mejeeji `start` ati `end`.
- `mode:"head"` / `mode:"tail"` — first/last `n` ila.
- `mode:"stats"` — ila, iwa, ati baiti ka lai si ara.

Lo `mode:"lines"` pẹlu `start`/`end` lati rin bulọki gigun ni awọn oju-iwe ju ki o beere gbogbo nkan ni ẹẹkan.

### Iforukọsilẹ irinṣẹ

Ohun elo imupada jẹ orukọ lọwọlọwọ `omniroute_ccr_retrieve` (iṣaaju `omniroute_` jẹ iṣẹ ṣiṣe ti ọjọ kan fun awọn ikọlu orukọ olupin-agbelebu). Orukọ ọpa ti o ni opin-suffix ti o mọ ati atunṣe fun awọn abajade MCP JSON ti a ge ni aarin-okun ni a tọpinpin bi awọn atẹle ti oke; oju-iwe yii ṣe akosile lọwọlọwọ, ihuwasi ti o firanṣẹ nikan.

### Igbesi aye igba

Awọn akoko ṣiṣan-HTTP laišišẹ ati olupin n ṣajọ wọn; ferese ti ko ṣiṣẹ ni igbagbogbo `MCP_SESSION_IDLE_MS` (ti a tọka si nipasẹ orukọ, kii ṣe iye koodu lile, nitorinaa oju-iwe yii ko lọ nigbati o yipada). Awọn aami aisan ti igba ikore laišišẹ jẹ HTTP 404 pẹlu `Unknown Mcp-Session-Id` — atunṣe ni lati tun sopọ tabi tun bẹrẹ igba naa,** kii ṣe** lati yi bọtini kan pada, yi aaye kan pada, tabi tunrukọ ohun elo kan.

## Dopin & imukuro

**Awọn ifibọ ti wa ni ko fisinuirindigbindigbin.** `open-sse/handlers/embeddings.ts` ko pe eyikeyi engine funmorawon — awọn ara request/response kọja taara si awọn executor laifọwọkan. Eyi jẹ igbekalẹ loni (awọn ifibọ ati awọn ipari iwiregbe jẹ awọn olutọpa pinpin), kii ṣe ayẹwo akoko asiko, ṣugbọn o tumọ si ibakcdun-idarudapọ ni #8034 ko ni oju ifihan ni ọna awọn ifibọ.

**àlẹmọ iyasoto Per-model/endpoint (#8034).** Fun awọn ipari iwiregbe, oniṣẹ le fun lorukọ ids awoṣe / awọn ibi-afẹde `provider/model` ti ko gbọdọ fisinuirindigbindigbin — ọna aabo kan ti o wulo ti titẹkuro ba jẹ ti firanṣẹ nigbagbogbo si ọna awọn ifibọ-isunmọ nigbamii, ati ni gbogbogbo wulo fun awoṣe eyikeyi eyiti awọn ọran iyara baiti-fun-baiti gangan (awọn ipinnu ipinnu, awọn ami-iṣaaju kache-kókó, ati bẹbẹ lọ).

- Aaye awọn eto: `exclusions?: string[]` lori konfigi funmorawon agbaye (`GET`/`PUT /api/settings/compression`), tẹsiwaju nipasẹ aaye orukọ funmorawon `key_value` ti o wa tẹlẹ (`src/lib/db/compression.ts`) — ko si tabili tuntun.
- Dasibodu taabu:** Dasibodu → funmorawon → Iyasoto** (`/dashboard/compression/exclusions`).
- Ilana sintasi: `*` nikan ni wildcard. Gbogbo awọn metacharacter regex miiran ninu apẹrẹ kan ni o salọ ṣaaju ki o to baamu, nitorinaa `gpt-5.6` baamu okun gangan nikan, rara `gpt-5x6` (ReDoS-ailewu, bounded, ko si awọn iwọn itẹ-ẹiyẹ). Awọn ilana baramu ọran-aibikita si mejeeji id awoṣe igboro ati akopo `provider/model` — `gpt-5-6`, `openai/gpt-5-6`, ati `openai/*` gbogbo iṣẹ, ati `*` nikan yọkuro gbogbo awoṣe.
- Baramu: `isCompressionExcluded()` / `normalizeCompressionExclusions()` ninu `open-sse/services/compression/exclusions.ts`. `chatCore.ts` ṣayẹwo ibi-afẹde ti a yọkuro lẹsẹkẹsẹ lẹhin ipinnu awọn eto funmorawon,** ṣaaju ki eyikeyi engine nṣiṣẹ** , ati ki o toju a baramu gangan bi funmorawon jije agbaye alaabo — awọn ara ìbéèrè jẹ provably baiti-aami. Rekọja naa ti gbasilẹ nipasẹ `writeCompressionSkip(..., "excluded")` fun hihan atupale.
- Aiyipada (akojọ empty/absent ): aami si pre-#8034 ihuwasi — ko si ohun ti a yọkuro.

## Awọn idiwọn ti a mọ

- **LLMLingua-2 (SLM) nilo awọn deps iyan ti o wa lapapo.** Osise nikan nṣiṣẹ ni iṣelọpọ iṣelọpọ nigbati awọn ẹlẹgbẹ `@atjsh/llmlingua-2` + wa ni ipo-ọkan si `dist/node_modules` (wo `scripts/build/colocateOptionals.mjs`, #4286). Laisi wọn engine kuna-ṣii (da ọrọ atilẹba pada). Ipinnu oṣiṣẹ ko da lori `import.meta.url` mọ (o ku ni lapapo adaduro) — o dakọ lori asiko asiko cwd / `argv[1]`.
- **Awọn akopọ ede Caveman `de` / `fr` / `ja` jẹ apa kan.** Wọn gbe awọn ofin `context` + `filler` + `structural` ṣugbọn ko si awọn idii `dedup` / `ultra`, nitorina kikankikan `ultra` ko lagbara ju `full` fun awọn ede wọnyẹn (wọn lo awọn ofin tiwọn nikan — ko si isubu ipalọlọ-pada si awọn ofin `dedup`/`ultra` Gẹẹsi, eyiti yoo mangle ọrọ ajeji). `en` / `es` / `id` / `pt-BR` ti pari. Awọn ifunni ti `dedup.json` + `ultra.json` fun awọn akopọ apa kan jẹ itẹwọgba.
